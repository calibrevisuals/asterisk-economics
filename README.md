# asteriskeconomics.com

The Asterisk Economics website, served by GitHub Pages. These are built files: the source (site.json, build.mjs, sources.mjs, sources/*.json) lives in the channel's project folder (fine-print-economics/website/). Rebuild there with `node build.mjs && node sources.mjs`, then copy dist/ here (without preview.html). Never delete CNAME.

Hourly job (.github/workflows/videos.yml): `videos.mjs` refreshes videos.json from the channel's YouTube feed (the "More episodes" row on each sources page reads it), then `titles.mjs` gives each sources page its video's live YouTube title (matched by data-yt), then `home.mjs` rebuilds the home page's episodes section (latest episode + a grid of every public long video, with Sources links) between the `videos:start`/`videos:end` markers in index.html. It runs every hour, so a new upload shows on the home page within about an hour of going public. The feed only lists the 15 newest uploads, so videos.mjs keeps older videos from the previous videos.json while YouTube still shows them publicly. After copying a rebuilt page here, run `node .github/scripts/titles.mjs` before pushing.

After pushing, open the new page's live URL. If no "pages build and deployment" run starts within a few minutes (it happened on 5 Nov 2026 after a git push), make a small real commit through the GitHub API (for example to this README); that starts a build.
